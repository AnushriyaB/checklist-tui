# checklist-tui

Write a note. Get a checklist. Check things off in the terminal.

Saved locally. No account. No API key.

## Install once

Needs [Node 18+](https://nodejs.org). Then:

```bash
npm install -g checklist-tui
```

After that, from **any folder**:

```bash
checklist
checklist "trip to sf for 10 days"
checklist update
checklist uninstall
```

Press **?** for keys. Press **g** to generate.
