# checklist-tui

Type a goal. Get a checklist. Check things off in the terminal.

Saved locally at `~/.config/checklist/data.json`. No account.

## Run

```bash
npm install
npm run dev
```

Or generate from the shell:

```bash
checklist "plan a 3-day trip to Lisbon"
```

Node 18+. Press **?** for keys.

## AI

Generation needs your OpenRouter key. Everything else works offline.

```bash
export OPENROUTER_API_KEY="your-key"
```

Private. Not open source.
